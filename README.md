# SPC RAKER

A browser arcade shooter built with plain HTML, CSS, and JavaScript.

## Features

- Two selectable pilot characters
- Shooting attacks with rapid fire and spread upgrades
- Boss waves as your score increases
- Power-ups including shields, spread shots, rapid fire, extra lives, slow motion, and a screen-clearing bomb
- Built-in synth sound effects for firing, hits, pickups, boss events, and game over
- Easy, Normal, Hard, and Insane difficulty modes
- Pause/resume and a local leaderboard

## Run it locally

From this project folder, start a simple local server:

```bash
python -m http.server 8000
```

Then open http://localhost:8000 in a browser.

## Controls

- Move: Arrow keys or WASD
- Mouse: Move the cursor to steer the ship
- Shoot: F, J, K, or left click
- Pause/resume: P or the Pause button
- Start: Click Start Game or press Space

## How to play

Choose a pilot and difficulty, then start a run. Easy mode gives you five lives, slower hazards and enemy shots, less frequent boss waves, and weaker bosses. Dodge incoming meteors, satellites, and enemy fire while shooting to destroy hazards and bosses. Collect power-ups for rapid fire, spread shots, shields, an extra life, seven seconds of slow motion, or a bomb that clears hazards and damages bosses. Keep moving during boss waves, and try to beat your high score.
