# SPC RAKER

A browser arcade shooter built with plain HTML, CSS, and JavaScript.

## Features

- Two selectable pilot characters
- Shooting attacks with rapid fire and spread upgrades
- Boss waves as your score increases
- Power-ups including shields, spread shots, rapid-fire boosts, and repair
- Built-in synth sound effects for firing, hits, pickups, boss events, and game over
- Normal, Hard, and Insane difficulty modes
- Pause/resume and a local leaderboard

## Run it locally

From this project folder, start a simple local server:

```bash
python -m http.server 8000
```

Then open http://localhost:8000 in a browser.

## Controls

- Move: Arrow keys or WASD
- Mouse: Move the cursor to steer the ship
- Shoot: F, J, K, or left click
- Pause/resume: P or the Pause button
- Start: Click Start Game or press Space
